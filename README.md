
# Shop Browser — CS Elective 2 Prelim Exam

Flutter e-commerce product browsing application based on the provided prelim exam requirements.

## Included requirements

- Home product grid
- `GridView.builder` / sliver grid
- 2 columns on phone-width screens
- 3 columns on tablet-width screens
- 4 columns on wider desktop/tablet screens
- Product detail page
- `go_router` Navigation 2.0 routing
- Add to cart
- Stateful quantity controls
- Live subtotal and total
- Checkout confirmation
- Empty-cart protection
- `Scaffold` + `AppBar` on every screen
- `Card`, `Image`, and `Text` widgets
- Single app theme
- Light/dark mode toggle from Home AppBar
- Stateless product cards
- Stateful product detail/cart behavior

## Run

```bash
flutter pub get
flutter run
```

## GitHub branch

For the exam submission, create the required branch:

```bash
git checkout -b PrelimExam
git add .
git commit -m "Create Prelim Exam Shop Browser app"
git push -u origin PrelimExam
```

The exam instructions specify the branch name `PrelimExam`.
